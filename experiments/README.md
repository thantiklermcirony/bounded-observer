# Experiments

Tests with dated local analysis plans, data and code. Failures are kept. The plans do not carry
an independent external registration timestamp.

| Folder | Claim | Result |
|---|---|---|
| `h1-decrease/` | Mechanistic overlap predicts position on the one-horizon dial | **Refuted as stated.** rho = -0.12, p = 0.76, 210 blocks, 36 pairs. Independently reproduced. Restated as a statement about surfaces. |
| `t1-power-audit/` | H1's design could separate the dial laws it compared (loss condition for the review's diagnosis D1) | **Could not.** Median Bliss–Loewe gap 0.50 of single-agent noise; 0.14 of model misfit. H1 stays refuted as stated but carries little weight against the dial reading. |
| `h2-effect-scales/` | The flat effect scale is the least consistent across trials | **Replicated.** 11 of the 14 heterogeneous meta-analyses out of 19. |

Each folder contains its local plan, the analysis code, the
derived tables, and a report that states the result as it came out.

# IDA

IDA — I Develop Awareness — investigates which measurements distinguish states that require different interventions, and whether acting on those distinctions improves an independently assessed later outcome.

It is the measurement-and-action branch of The Bounded Observer. Its relation to the foundation is the sufficient-record question: what information changes a future reading or useful action? Physiology and intervention effectiveness require their own measurement bridge and empirical comparison.

## Two current instruments

| Instrument | What exists | Scientific status |
| --- | --- | --- |
| [IDA Live](../../apps/ida-live/README.md) | Headband/replay acquisition, frozen reference, chosen hyperbolic feature map and research session tools | The map's physiological interpretation and added predictive usefulness remain unvalidated |
| [StateAtlas](https://github.com/thantiklermcirony/ida-stateatlas) | Synthetic discovery lab, experiment design, physiology-analysis records and R1 engineering baseline | Synthetic matrices are dimensionless; R1 is not fabricated or physically validated; existing analyses do not establish useful added prediction |

StateAtlas currently runs no generative model and delivers no human intervention. IDA Live is a separate research application with its own acquisition and session capabilities. Neither instrument derives consciousness from UHL.

## Operational contract

| Item | IDA specification |
| --- | --- |
| Record | Signal history, calibration, uncertainty, intervention and outcome logs |
| Normalizer | The declared frozen reference or assay calibration |
| Readings | Present features, return dynamics and proposed action-relevant distinctions |
| Operations | Recorded measurement/session actions and explicitly specified intervention protocols |
| Retained state | History needed to distinguish independently assessed future outcomes |
| Composition | Declared feature map and update order; Einstein addition is not automatically a physiological mechanism |
| Time/resources | Sampling, perturbation, return and diagnostic delays |
| Bridge | Features must predict an independent outcome and improve action against a strong fixed comparator |
| Next discriminating task | Matched-present, common-future protocol with independently assessed behavior and held-session evaluation |

**[H]** Return dynamics or recovery residues may add useful predictive or intervention information. The loss condition is failure to meet the specified held-out improvement criterion against the fixed comparator. Its experimental protocol must set the threshold before observing the decisive outcomes.

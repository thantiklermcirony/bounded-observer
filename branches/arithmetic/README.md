# Arithmetic and predictive records

The arithmetic line studies which divisibility distinctions survive projection or refinement, and which unresolved factors are needed to support a later reading.

Existing manuscripts include recursive predictive closure in the prime sieve and prime-residue projection tomography. Their [historical identifiers and statuses](../../registry/atlas.csv) remain distinct from the current physical record library.

## Operational contract

The record contains divisibility state, wheel coordinates and finite offset patterns. Readings include survivor and gap-word functionals. Updates use Chinese-remainder refinement and exact marginalization. The retained state separates explicit wheel factors from unresolved Euler factors.

A refinement index or arithmetic scale is not physical elapsed time. Exact constructions need no physical bridge. A finite density is used as a probability only where its positivity and normalization are established.

Exact projection identities are separate from asymptotic approximation or predictive success for actual primes. The latter needs independent enumeration and controlled bounds. This is a branch through record sufficiency and refinement; it is not an assertion that primes are a physical hyperbolic field.

# Inside · visual essay production notes

The public animation is in site/inside-film.mjs. It is an original, silent,
captioned motion piece. Each scene carries its status and boundary in
FILM_SCENES; the page also exposes those notes as text. It does not simulate
subjective consciousness or claim that real societies follow the valley's rules.

## Optional voiceover script

This script is available if the piece is later exported as a voiced video.
It is not synchronized audio in the current site.

| Time | Scene | Narration |
| --- | --- | --- |
| 0:00–0:18 | Inside the world | There is no seat outside the world. An observer measures from somewhere within it. Light arrives, memory keeps fragments, and every action returns to the same world that made the observer. |
| 0:18–0:35 | What survives | The place we grow up, the work we do, the people who speak to us: these shape what we notice. An event becomes a record. A child receives that record, not the whole event. |
| 0:35–0:55 | One event, two views | A gate closes between two communities. Downriver, the channel thins. Upriver, the water rises behind the wall. Each side carries an older story. They may disagree sincerely because they can reach different evidence. |
| 0:55–1:16 | One reading, two futures | Now strip the story to one reading. Two histories arrive at the same number. Give them the same pulse and their futures part. If a summary merges histories that respond differently to an allowed action, it is not enough to be the state. |
| 1:16–1:36 | Which actions count? | Even action has to be checked. Try one intervention from rest, then from another state. If the first result cannot determine the second, hidden context remains. A single law of change has not yet been earned. |
| 1:36–2:02 | Two ways to read a step | Under four specific conditions: continuous combination, associativity, strict monotonicity, and a neutral state, a bounded quantity has an additive coordinate. Equal steps there crowd toward an edge on one chosen bounded chart. The edge is a horizon for finite lawful steps. A saturation curve alone does not prove those conditions. |
| 2:02–2:17 | A route can leave a turn | In a separate, selected geometry, carry a direction around a loop. It returns turned. The route itself has left a trace. That geometry needs its own assumptions. |
| 2:17–2:35 | Compare with the world | Pull back by comparing records, not by pretending to leave the world. Some claims survive tests. Some fail. Some remain open. Understanding another account can change a future action; it cannot grant their entire experience or guarantee agreement. |

The spoken duration of this optional script has not been measured. Retiming is
required before pairing it with the current 2:35 picture.

# Repository roles

The canonical project is [The Bounded Observer](https://github.com/thantiklermcirony/bounded-observer). Its current library, branch registry and public explanation define the shared entrance.

| Repository | Role | Transition |
| --- | --- | --- |
| bounded-observer | Current foundation, project website and branch registry | Add the October library and new project map; keep frozen v2.1 and the earlier walk |
| empirical-architecture | Earlier manuscripts, foundations and executable certificates | Point its entrance to the shared project; preserve source identifiers and history |
| empirical-observatory | Experiments, data, applications and laboratory evidence | Keep workflows and large data here; connect each line to its branch and dated result |
| ida-stateatlas | Independently maintained StateAtlas application | Link the IDA branch and current common foundation; keep its own capabilities and tests |
| boundedness-atlas | Earlier public synthesis and source history | Identify its historical role and point visitors to the current entrance |
| thantiklermcirony profile | Author entrance | Present one programme and its branches; link component repositories by role |
| Engineering working copies | Contributions to upstream projects | Preserve upstream review and code history; catalogue the specific contribution |
| Domain reviews | Source-specific historical work | Preserve the record and label the relationship to the programme explicitly |

The [live repository inventory](../registry/repositories.json) records eighteen public repositories inspected on 13 October 2026. No repository deletion, renaming, archival or new repository is required for this consolidation.

The GitHub Virtual Cell flights and Arc competition are separate branch entries. Competition implementation archives and large cellular data are not copied into the mathematical hub. A future maintained competition source release can live under the existing laboratory component or an application directory; its branch identity remains stable.

Update component entrances with the canonical project link and role before treating the transition as public. Old sites, manuscript identifiers and source URLs remain available. Supersession is expressed by a dated correction or current-authority link, not by removing the historical result.

Future projects start with the [branch contract](branch-contract.md). A separate component repository is justified by maintenance, release or data needs, rather than a new theoretical root.
